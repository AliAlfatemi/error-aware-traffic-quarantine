# Security policy

## Supported scope

Only the current default branch and latest tagged release are maintained. This
is research software, not a deployment-ready network defense.

## Reporting a problem

Report suspected vulnerabilities privately to `aalfatemi@fordham.edu`. Do not
post credentials, private hostnames, account names, sensitive packet captures,
or exploit details in a public issue.

Use the software only on systems and traffic for which you have explicit
authorization. Example configurations are not permission to test a third-party
network.
